# The GC removes a TMPDIR directory only when its name is exactly
# <prefix>-<random suffix> for a prefix listed here. Ownership is proved by
# this list, not inferred from shape or contents, so another tool's directory

# every mkdtemp call in the repo, so a new prefix fails CI rather than going
# unnoticed. Regenerate with:
#   grep -rhoE 'mkdtempSync\(join\(tmpdir\(\), *"[^"]+"' --include='*.ts' commerce apps lib \
#     | sed -E 's/.*"([^"]+)".*/\1/' | sed -E 's/-$//' | sort -u
