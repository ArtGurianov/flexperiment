# Платный LMS — черновик оферты под нативную Точку и «Точка Чеки» (2026-11-22)

Задание (6) координатора · E · **черновик, не утверждён, не опубликован, продажи закрыты**. Основание —
решение владельца «Native launch and fiscal profiles» (docs/v2-merchant-schema.md, Authority boundary, #294):
первый платный LMS — интернет-эквайринг Точки и «Точка Чеки», готовые опубликованные материалы с автоматической
выдачей, один чек `FULL_PAYMENT`, отдельный чек возврата; курсы с будущими обязательствами — отдельная квалификация.

Основа текста — утверждённая закрытая редакция `closed-paid-test/2026-10-16-review-5` (её байты не менялись).
Отличия: нет маршрута через Refref; цена/курс из подтверждения заказа, а не фиксированные 1 ₽ / Test Course;
оговорка о курсах без будущих обязательств; порядок при неактивированном доступе после оплаты; возможная
будущая смена фискального сервиса без изменения условий прежних заказов (целевой провайдер — OFD.ru Ferma).
